# WeChat26Demo 0.3.1 — 文字历史与弹性叠牌

在已交付的 0.3.0 本地笔记版本上修改。最低 iOS 26.0，arm64；Bundle ID 仍为 `com.xyy.wechat26demo`，构建号 6。

## 本次修改

- 预置历史全部改为文字。首次打开 0.3.1 时，在原存档内把旧的内置示例图片消息转成文字，不重建聊天；自己发送的文字、图库照片、头像、昵称、群名、背景、草稿和开关保留。图片文件丢失或无法解码时显示紧凑的文字提示，不再留一块空白图片；部分照片损坏时其余照片仍能展示。
- 聊天右上角恢复为“搜索 + 详情”共用一个系统玻璃胶囊。首页加号不再根据导航路径手动销毁和重建，交由 NavigationStack 管理进入、返回和侧滑取消；删除上一版的分隔玻璃按钮。
- 通讯录右上角图标约束到 21pt 并校正视觉中心；功能列表图标统一放在 28pt 的栏位，限制宽度，群聊图标不再撑宽。群头像拼图中，每一张自定义小头像也单独裁切连续圆角。
- 附件恢复到输入栏上方，四列两行、整块原生液态玻璃背景。八块半透明圆角矩形同时包住图标和文字，适配深浅色及“降低透明度”；不再使用悬浮在一角的小面板。50pt 的麦克风、输入胶囊和加号保持原尺寸、间距、字体及材质。
- 叠牌改为独立 UIKit 图片层：顶层跟手，下层逐层跟随位移和转角，松手后回弹。下层带渐强的模糊。轻拖不切换照片，明显横滑才翻牌；轻点展开全部照片，轻点某张收成新的封面，长按进入大图。
- 图片解码和模糊预处理放在后台，动画帧只更新现成图片层的变换和透明度。最多展示五层叠牌；停止运动、离开视图后停止刷新，释放离屏视图的图片引用。启用 ProMotion 的刷新率提示，实际帧率由系统、电量及设备状态决定。

## 入口

- 自己：`我 → 顶部个人资料`，或轻点自己消息旁的头像。
- 联系人：`通讯录 → 联系人 → 修改头像和昵称 / 备注`；也可轻点消息头像或打开聊天详情。
- 群聊：`聊天右上角详情 → 顶部群资料`；下方群成员头像可分别修改。
- 图库发送：`聊天加号 → 照片`。选好后按系统选择器的完成按钮，等待导入提示结束。
- 清空：`聊天详情 → 清空聊天记录`，需要确认。

## 保存规则

首次运行且本地没有存档时才载入示例数据。以后读取存档，包括用户主动清空的状态，不用示例覆盖。消息与图片保存到应用的 Application Support 目录；图片使用独立文件，元数据使用原子替换并保留上一份完整备份。读取失败时保留原文件并提示，不自动重新初始化。未发送草稿在停顿 0.3 秒、离开页面或应用失去前台时写回。

0.2.0 没有持久化，已经随进程结束丢失的数据无法从该工程包追回。0.3.0 开始保存的新内容可在正常退出和重启后恢复。升级时保持相同 Bundle ID 并覆盖安装；卸载应用会删除它的本地数据。

照片副本最长边 2048 像素，头像最长边 512 像素；导入时校正方向。系统 PhotosPicker 按选择顺序导入，最多 30 张。系统 Quick Look 负责大图翻页、缩放和分享，聊天内叠牌使用本项目的 UIKit 动画实现。

附件的照片和拍摄可用；语音输入引导使用系统键盘听写。通话、位置、红包、转账和礼物目前仅有演示入口。

## 编译与验证

ZIP 内直接是工程根目录文件，不套额外文件夹。覆盖原仓库后按原有 GitHub Actions 流程构建和签名。手机终端指令见 `GITHUB_BUILD_CN.md`。

新增 `StackSpring.swift`、`ElasticPhotoStack.swift` 和 `Tests/MigrationAndMotionTests.swift`；Makefile 和 CI 源文件清单已更新，无第三方包依赖。GitHub 构建会先运行 Foundation 测试，检查旧格式读取、迁移不丢失用户内容、迁移幂等、磁盘回读、弹簧在不同时间步下的响应与收敛，再构建 iOS 应用。

本次已完成 Swift 语法树、输入栏源码差异、Makefile 清单、资源、plist、脚本和 ZIP 完整性检查。当前执行环境没有 Swift 编译器、Xcode 或 iOS SDK；尚未执行 Foundation 测试二进制、iOS 编译和真机动画测试，不能据此保证真机帧率或与视频完全一致。

安装时保持相同 Bundle ID 并覆盖安装，以继续使用 0.3.0 的应用数据。优先检查：原来的空白示例历史是否变成文字；之前发送的照片、备注和头像是否仍在；右上角进入/返回及侧滑取消；叠牌小幅来回拖动、翻牌、展开收起；修改群成员头像后缩略图圆角；结束进程再打开。

实现参考：[Apple ToolbarItemGroup](https://developer.apple.com/documentation/swiftui/toolbaritemgroup)、[CADisplayLink](https://developer.apple.com/documentation/quartzcore/cadisplaylink)、[ProMotion 刷新率](https://developer.apple.com/documentation/quartzcore/optimizing-iphone-and-ipad-apps-to-support-promotion-displays)。
