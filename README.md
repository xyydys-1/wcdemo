# WeChat26Demo 0.3.3 — 首页模式、群成员与照片叠牌细调

基于用户提供的 0.3.2 compilefix2 直接修改，最低 iOS 26.0、arm64，Bundle ID 仍为 `com.xyy.wechat26demo`。版本号更新为 0.3.3，构建号 9；覆盖安装继续读取原有本地数据。

## 0.3.3 改动

- **照片叠牌**：底层照片模糊明显加重；拖动跟随改为前景 100%、第二层约 30%，更深层依次约 16% / 9% / 5%，避免整叠一起移动。
- **好友真实写入**：添加朋友页现在可填写账号/手机号与可选昵称，确认后写入本机 JSON 存档，重启后仍保留；通讯录“新的朋友”和右上角添加入口均可进入。
- **群成员可继续增加**：群聊详情显示实时成员数，并增加“添加”格；可从现有通讯录多选成员加入群聊。聊天标题同步显示当前群人数。
- **群头像轮廓**：群头像继续按最多四人拼接，但整张拼图改为统一外轮廓裁切，外圆角比普通单头像更小。
- **首页两种显示模式**：默认模式保持原来的 inset grouped 圆角分组；新增“紧凑”模式，改为直接列表，置顶行使用更深的系统背景区分。右上角 `+` 菜单增加“显示模式 → 紧凑 / 默认”。
- **置顶收起/展开**：置顶标题右侧增加折叠按钮，状态使用 AppStorage 保存。
- **聊天页加号玻璃延迟**：原实现把 glassEffect 直接挂在 Menu label 上，菜单收起动画期间系统会临时接管该 label 的呈现，导致圆形玻璃短暂晚一拍恢复。现在把玻璃圆形作为独立、持续存在的底层视图，Menu 只负责点击与弹出，因此收起时无需等待 Menu label 再生成玻璃。

## 本地数据

没有改变 `DemoArchive` 的 schemaVersion，也没有重置聊天记录。新增好友和新增群成员仍通过现有原子存档逻辑保存。首页显示模式和置顶折叠状态使用系统 AppStorage 保存，不影响旧 JSON 的兼容性。

## 构建验证

已在当前环境执行所有 Swift 文件的 `swiftc -frontend -parse` 语法解析并通过。当前环境没有 iOS SDK / Xcode，无法完成真正的 iOS 链接编译和真机 UI 验证；Foundation 测试在 Linux 上因缺少 CoreGraphics 模块无法运行。

手机更新与 GitHub Actions 编译指令见 `GITHUB_BUILD_CN.md`。
