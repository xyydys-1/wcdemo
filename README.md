# WeChat26Demo 0.3.3

在 `0.3.2 NativeSwiftUI compilefix2` 上继续修改。最低 iOS 26.0，arm64，构建号 8；Bundle ID 仍为 `com.xyy.wechat26demo`。

## 本次修改

- **输入框保留**：麦克风、输入胶囊、表情的布局、50pt 高度、字体、间距和玻璃代码不变；收起时加号也保留原来的外观。
- **照片叠牌**：从前至后，跟随位移比例为 100%、40%、20%、10%、5%，后层响应更慢，回弹由 SwiftUI 弹簧执行。后四层模糊分别为 2.8、4.3、5.6、6.8pt；展开后全部清晰。左右翻牌统一为当前首张移到队尾、下一张成为封面。不可见层退出时保留短暂的已解码图片，避免退出动画中闪成空卡。
- **触摸与滚动**：用公开的 UIGestureRecognizerRepresentable 接入系统 UIPanGestureRecognizer，识别开始前区分方向；竖向意图不接管。展开网格时停用翻牌识别器。照片轻点展开／收起、长按 Quick Look 大图继续保留。
- **附件大面板**：采用 iOS 26 默认的部分高度 sheet，从原加号通过 matchedTransitionSource + navigationTransition(.zoom) 展开，背景不覆盖自绘颜色或材质。面板内固定四列两行，八块灰色半透明圆角按钮用系统 ultraThinMaterial，标题位于下方。ButtonStyle 只增加轻微按压放大和系统 spring 回弹。照片选择器、相机等在面板完成关闭后再打开。
- **保留原附件菜单**：“我 → 设置 → 附件展开方式”可在“大面板”和之前的原生 Menu / ControlGroup 之间切换。
- **图片边缘统一**：头像、群拼图内小头像、单张照片、叠牌和资料编辑预览采用共享的 photoSurface：连续圆角、抗锯齿裁切，加一圈窄的系统 clear glass 底边。照片本身不加玻璃滤镜；移除旧叠牌手绘渐变描边。叠牌图片仍在旋转前合成，并保留透明像素采样边。
- **群成员可编辑**：群详情显示实际人数，58pt 成员头像、14pt 昵称，末尾保留虚线“＋”头像位。可以多选已有朋友添加，也可当场创建新朋友。长按成员可编辑资料或移出群聊，自己不可移出。群拼图随人数更新，最多显示九个头像。
- **更多朋友**：补充 12 个默认联系人，初始通讯录共 21 人；新增只执行一次，保留已有资料。通讯录右上角和“新的朋友”现在可以实际创建联系人、选择头像并保存。默认人物头像使用已有图片资源，不再显示彩色 SF Symbols 占位头像。
- **列表与设置**：首页加号增加原生“显示模式 → 紧凑 / 默认”二级菜单；置顶标题右侧可收起／展开，默认模式置顶底色较深。聊天行分割线的起点明确对齐标题，通讯录和设置行也统一缩进。通讯录、发现、我、聊天设置的左侧改为圆角图片图块，新增 29 张内置 PNG 资源。

## 保存与兼容

沿用 `Application Support/WeChat26Demo/notes-v1.json` 和原 Media 目录，schemaVersion 保持 1。新增目录版本、显示模式、置顶折叠和附件菜单偏好均为可选字段，旧存档不含这些字段也能读取。

文字、发送的图片、头像、昵称／备注、群名、成员列表、壁纸、开关和草稿都继续本地保存。成员编辑和设置先保存成功才更新界面。发送照片使用本机副本，不依赖照片选择器的临时 URL。

旧示例图片转文字的迁移继续保留；不会重新播种历史。已清空的聊天和已清空的通讯录不会恢复。额外联系人只添加一次，之后删除也不会在下次启动时重建。自定义头像和备注优先，不被默认资源覆盖。

照片导入保留最长边 2048 像素，头像最长边 512 像素。读取失败时保留存档并显示错误，不自动重建。升级应继续使用同一 Bundle ID 覆盖安装。

照片和拍摄可用，语音输入引导使用键盘听写。通话、位置、红包、转账和礼物仍是演示入口。

## 编译

本 ZIP 是平铺工程，解压后直接有 Makefile。手机完整指令见 [GITHUB_BUILD_CN.md](GITHUB_BUILD_CN.md)。新增 Swift 文件均加入 Makefile；工作流测试命令包含新增 DirectoryData 和目录测试。

保留 compilefix1 的 CoreGraphics 显式导入以及 compilefix2 的 CGFloat / [CGFloat] 显式声明；没有移除任何既有数据或照片布局测试。GitHub Actions 先执行存档、迁移、成员编辑、设置回读及照片布局测试，再用现有 macOS 26 / Xcode 26.6 配置编译和打包 IPA。

本地检查覆盖 Swift 语法树、输入框字节对比、资源和构建源清单、plist、Shell 与 YAML 结构、ZIP 完整性。**当前环境没有 Swift 编译器、Xcode 或 iOS SDK，未执行测试二进制、iOS 编译或真机测试。** 流畅度、玻璃外观及参考视频的接近程度仍需设备验证。

照片部分是公开 API 的组合实现；没有把它声称为苹果提供的现成聊天叠牌组件。依据见 [REFERENCE_SPEC.md](REFERENCE_SPEC.md)。
