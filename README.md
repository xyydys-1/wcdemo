# WeChat26Demo 0.3.2 — 系统菜单与 SwiftUI 照片布局

本包为 compilefix2：保留 CoreGraphics 导入修复，并将照片布局测试的比例常量明确声明为 CGFloat、数组声明为 [CGFloat]，消除 zip 中混合数值数组被推断为 [Any] 的编译错误。布局输入与断言复用同一数组，保留全部测试。输入框、动画、存档、版本号和构建号保持不变。

在 0.3.1 compilefix1 上继续修改，最低 iOS 26.0、arm64，构建号 7。Bundle ID 保持 `com.xyy.wechat26demo`。

## 本次改动

- **输入框保持原样**：麦克风、输入胶囊、表情图标的代码保留，50pt 高度、间距、字体及玻璃材质不变。加号收起时仍使用原来的 50pt 圆形按钮外观。
- **附件使用真正的系统 Menu**：八个操作放进两个 ControlGroup，菜单弹出、关闭、玻璃厚度、阴影、点击反馈和外部点击收起交给系统。去掉原先手写的 PlusPanel、缩放、淡入淡出及颜色底板。和首页右上角使用同一种系统菜单呈现。
- **照片改用 SwiftUI 布局与弹簧**：保留同一组照片视图，AnyLayout 在叠放和展开之间切换。拖动使用 interactiveSpring，回弹使用 interpolatingSpring；不同层的响应与位移不同。移除 UIKit 叠牌视图、CADisplayLink 循环和手写弹簧积分。
- **展开布局按视频重排**：三张及以上均用三列，包含四张的情况；每行高度由该行最高照片决定，横图和竖图在行内居中。展开可比叠牌更宽，保留实际比例，不再额外预留方形单元格或“收起照片”底栏。轻点一张照片即可收起并切换封面。
- **模糊和边缘**：下层使用逐层增强的 SwiftUI blur；模糊后再裁连续圆角、绘制细内描边。图片、模糊和描边在旋转前一起合成，保留一个透明像素的采样余量。描边是 SwiftUI 的 strokeBorder，不是未公开的苹果照片效果。
- **拖动开销**：只有运动修饰器读取连续手势，聊天布局不订阅每一帧位移。缩略图在后台按叠牌／网格尺寸解码并缓存；叠放只展示最多五层，展开可查看全部所选照片。小幅拖动回弹，明显横滑翻牌；拖动结束后抑制误触展开，竖向拖动允许聊天列表滚动。

系统 Menu 会根据空间与辅助功能设置决定组内布局、图标和标题的显示，不能强制保证视频中固定四列八块的逐像素外观。照片部分是公开 SwiftUI API 的组合实现；未发现可以直接复用的 iOS“聊天照片叠牌”组件，不能把它称为苹果内置叠牌。视频作者使用 iOS 26 SDK，也不能证明每个界面都是系统现成控件。

## 使用与保存

加号 → 照片：使用系统 PhotosPicker，按选择顺序导入，最多 30 张。轻点叠牌展开，轻点展开后的照片收起，长按进入系统 Quick Look 查看大图、缩放和分享。

自己在“我 → 顶部资料”编辑；联系人可从通讯录或消息头像编辑；群聊资料及群成员在聊天详情编辑。头像来自本机图库，昵称、备注和群名可保存。

沿用原有本地存档和照片目录，首次安装才建立文字示例历史。升级继续读取已保存的文字、图库照片、头像、昵称、群名、壁纸、开关与草稿；不会重新初始化。0.3.1 的示例图片转文字迁移和损坏图片的紧凑文字提示保留。保持相同 Bundle ID 并覆盖安装即可继续使用本地数据；卸载应用会删除应用数据。

照片保存副本最长边 2048 像素，头像 512 像素。导入成功后先写入本机文件，再保存消息；元数据使用原子写入并保留备份。读取失败保留文件并显示错误，不自动重建历史。

照片与拍摄功能可用；语音输入引导使用系统键盘听写。通话、位置、红包、转账、礼物保留演示入口。

## 构建与验证

ZIP 是平铺工程，根目录直接包含 Makefile、Swift 文件和 GitHub 工作流。手机更新及触发构建的完整指令见 [GITHUB_BUILD_CN.md](GITHUB_BUILD_CN.md)。新文件 `NativePhotoStack.swift`、`PhotoLayoutMetrics.swift` 已加入 Makefile；旧的 `ElasticPhotoStack.swift` 和 `StackSpring.swift` 已移除。

GitHub Actions 沿用工程的 macOS 26 / Xcode 26.6 配置。Foundation 测试覆盖本地存档回读、迁移不丢失用户内容、清空后不重建、图片顺序，以及四／六／三十张混合比例照片的布局边界。其后执行完整 iOS 编译和 IPA 打包。

当前环境已完成 Swift 语法树检查、输入框字节对比、数据相关源码对比、构建源文件清单、plist、脚本与 ZIP 完整性检查。**本地没有 Swift 编译器、Xcode 或 iOS SDK，未执行 Foundation 测试二进制、iOS 编译或真机测试。** 语法通过不代表编译通过，也不能据此保证帧率或与视频完全一致。
