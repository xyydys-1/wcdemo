# WeChat26Demo 0.3.4

本地离线 iOS 26 SwiftUI Demo。此包重新生成用于下载，保持输入栏三段式布局、系统原生附件菜单、圆角分组聊天列表、本地保存、资料编辑、群成员编辑和多图叠牌。

## 0.3.4 要点

- 输入栏保留麦克风 + 输入胶囊 + 加号三个 50pt 控件。
- 加号使用系统 `Menu` / `ControlGroup`，不使用大块自绘玻璃面板。
- 图片仅有一圈细微的半透明内描边，不在图片背后叠加 Liquid Glass。
- 多图叠牌下层跟随为约 40% / 20% / 10% / 5%，模糊逐层增加；左右滑动均把首张放到队尾。
- 图片拖动先等待明确横向意图，轻微抖动不移动；明显竖向意图交给聊天滚动。
- 默认聊天列表使用系统 `insetGrouped` 圆角分组；紧凑模式使用 `plain`。
- 联系人、群聊、自己均可改昵称/头像；群聊可增加或移除成员。
- 文字、图库图片、头像、备注、草稿、背景和设置保存到 Application Support。
- 首次安装使用纯文字示例历史；主动发送的照片会保留。

## 构建

最低 iOS 26.0，arm64，Bundle ID `com.xyy.wechat26demo`，版本 0.3.4 / build 9。

GitHub Actions 使用 Xcode 26.6 + Theos 构建 unsigned IPA。此环境没有 Xcode，因此交付前只进行了静态源码/归档检查，完整编译仍以 GitHub Actions 为准。
